# PROMPT.md

## Project Name
Expense Tracker

## Description
This document contains the AI prompts used during the development of the Expense Tracker web application.

---

## Prompt 1
Write JavaScript logic to:
- Render total salary on the DOM after form submission.
- Dynamically render expenses in a list.
- Calculate total expenses.

---

## Prompt 2
Add form validation to:
- Prevent empty input submission.
- Prevent negative values.
- Display appropriate error messages.

---

## Prompt 3
Implement LocalStorage to:
- Save salary.
- Save expense list.
- Restore all data after page refresh.

---

## Prompt 4
Implement a delete feature with a trash icon for each expense.
- Remove expense from the DOM.
- Recalculate remaining balance instantly.

---

## Prompt 5
Integrate Chart.js to display a dynamic pie chart showing:
- Remaining Balance
- Total Expenses

---

## Prompt 6
Generate an expense report as a downloadable PDF using the jsPDF library.

---

## Prompt 7  
Implement a threshold alert.
If the remaining balance drops below 10% of the total salary:
- Display a warning banner.
- Highlight the remaining balance in red.

---

## Prompt 8
Implement a "New Data" feature to:
- Clear all expenses.
- Reset salary.
- Remove LocalStorage data.
- Reset charts and UI.

---
